## Featured Projects

### Graph RAG vs. Vector RAG — Comparative Study *(in progress)*
Two independent, production-style RAG systems built to directly compare retrieval architectures on the same domain.

- **Vector RAG** *(completed)* — FastAPI · LangChain · Gemini 2.5 Flash · Supabase (pgvector) · Sentence Transformers
- **Graph RAG** *(building)* — FastAPI · Neo4j · Cypher · Gemini 2.5 Flash, with deterministic YAML ingestion and rule-based Cypher generation rather than LLM-generated queries

`FastAPI` · `LangChain` · `Neo4j` · `pgvector` · `Gemini`
